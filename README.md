# FocusFlow AI

FocusFlow AI is an Agentic AI-powered productivity and smart scheduling platform that intelligently plans, prioritizes, and adapts users' daily tasks based on goals, availability, and progress.

## Features

- Secure JWT Authentication
- Goal & Task Management
- AI-powered Smart Scheduling
- Adaptive Task Rescheduling
- Progress Tracking Dashboard
- Weekly Productivity Insights

## Tech Stack

### Backend
- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL

### Frontend
- React

### AI
- Gemini API
